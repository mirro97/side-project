## 1. 방향

### 1-1. 다크 테마 단일

**v1은 다크 테마만 만든다.** 라이트는 넣지 않는다.

이유는 콘텐츠다. 브롤러 이미지 106장과 맵 이미지가 전부 채도 높은 카툰 그래픽이라 밝은 배경에 깔면 화면이 소란스러워진다. 어두운 배경이 이미지를 받쳐주고, 게임 컴패니언 앱의 관례이기도 하다. 무엇보다 테마 두 벌은 토큰도 Figma 프레임도 두 배가 된다.

다만 **토큰은 시맨틱 이름으로 정의**해서 나중에 라이트를 추가할 때 값만 갈아끼우면 되게 한다. `gray-900`이 아니라 `bg-base`로 쓴다는 뜻이다.

### 1-2. 브랜드 톤

슈퍼셀 팬 콘텐츠 정책상 로고·공식 폰트 같은 브랜드 에셋은 쓸 수 없다. 색 톤은 자유다.

게임의 노랑은 **트로피 표시 전용으로 예약**하고 UI 액센트는 보라 계열로 잡는다. 트로피 숫자가 화면 어디에나 나오는데 액센트까지 노랑이면 무엇이 강조인지 구분이 안 된다.

## 2. 토큰

### 2-1. 색상 — 배경과 표면

```
  bg-base       #0F1117   앱 바탕
  bg-surface    #171A23   카드 · 목록 행
  bg-elevated   #212632   상세 패널 · 모달 · 드롭다운
  bg-overlay    #000000 60%  모달 뒤 딤
  border-subtle #262B38   카드 경계
  border-strong #39404F   입력 필드 · 포커스 링 바깥
```

### 2-2. 색상 — 텍스트

```
  text-primary    #F2F4F8   제목 · 주요 수치
  text-secondary  #A3ABBD   설명 · 라벨
  text-tertiary   #6B7385   비활성 · 보조 메타
  text-inverse    #0F1117   액센트 배경 위 텍스트
```

### 2-3. 색상 — 액센트와 시맨틱

```
  accent         #8B5CF6   기본 액센트 (버튼 · 선택 탭 · 링크)
  accent-hover   #A78BFA
  accent-subtle  #8B5CF6 16%   선택 행 배경 · 뱃지 바탕

  trophy         #FFC83D   트로피 아이콘과 수치 전용
  success        #3DD68C   승리
  danger         #FF5C6C   패배 · 에러
  neutral        #6B7385   무승부
  warning        #FFB020   점검 · 한도 초과 안내
```

### 2-4. 색상 — 순위

```
  rank-1  #FFD24A   금
  rank-2  #C9D2DE   은
  rank-3  #E08A4B   동
  rank-n  text-secondary 를 그대로 사용
```

1·2·3위는 배지에 배경색을 채우고, 4위부터는 배경 없이 숫자만 둔다. 세 자리 순위까지 나오므로 배지 폭을 고정한다.

### 2-5. 색상 — 희귀도

게임 원본 값을 그대로 쓴다. BrawlAPI `rarity.color`에서 온다.

```
  1  Common           #b9eaff
  2  Rare             #68fd58
  3  Super Rare       #5ab3ff
  4  Epic             #d850ff
  5  Mythic           #fe5e72
  6  Legendary        #fff11e     ← 원본이 "#fff11ev" 로 깨져 있어 보정한 값
  7  Ultra Legendary  #e1fb2a
```

주의할 점 두 가지.

- **Legendary 원본 색상값이 잘못된 hex다.** 빌드 파이프라인에서 hex 형식을 검증하고 보정 테이블을 태워야 한다
- **Legendary와 Ultra Legendary가 둘 다 노랑–연두 계열이라 나란히 두면 구분이 어렵다.** 게다가 트로피 색과도 가깝다. 희귀도는 색만으로 표현하지 말고 **항상 라벨 텍스트를 함께** 둔다

분포도 알아둘 것. Mythic 41 / Epic 30 / Legendary 15 / Super Rare 10 / Rare 8 / Ultra Legendary 2 / **Common 1**. 희귀도 필터에서 Common을 고르면 결과가 한 개뿐이므로 빈 화면처럼 보이지 않게 처리한다.

### 2-6. 타이포그래피

**Pretendard 단일 폰트**를 쓴다. 라틴 글리프가 Inter 기반으로 만들어져 영어 품질이 좋고 한글도 같은 패밀리에서 해결된다. 이중 언어 제품에서 폰트를 하나로 유지할 수 있는 몇 안 되는 선택지다.

Figma에서 쓰려면 데스크톱에 폰트를 설치해야 한다. 웹에서는 npm 패키지로 셀프 호스팅한다.

```
  display   32 / 700 / -0.02em    화면 타이틀
  title     24 / 700 / -0.01em    섹션 헤더
  heading   18 / 600              카드 제목 · 브롤러 이름
  body      15 / 400 / 1.6        본문 · 설명
  label     13 / 500              라벨 · 뱃지
  caption   12 / 400              메타 · 타임스탬프
  numeric   상속 / 600 / tnum      트로피 · 순위 · 스탯 수치
```

**`numeric`에는 `font-feature-settings: "tnum"`을 반드시 건다.** 랭킹 200행에서 숫자 폭이 흔들리면 목록이 지저분해진다. Figma에서도 텍스트 스타일에 Tabular Figures를 켜둔다.

### 2-7. 간격 · 라운드 · 그림자

```
  space   4 · 8 · 12 · 16 · 24 · 32 · 48        4의 배수만 사용
  radius  sm 6 · md 10 · lg 16 · full 9999
  shadow  panel   0 8 32 rgba(0,0,0,.45)        상세 패널 · 모달
          card    0 1 2  rgba(0,0,0,.30)        카드 (아주 약하게)
```

다크 테마에서는 그림자보다 **표면 밝기 차이로 층을 표현**한다. `bg-surface`와 `bg-elevated`의 대비가 주 수단이고 그림자는 보조다.

### 2-8. 모션

```
  instant   100ms   호버 · 포커스
  fast      180ms   패널 열림 · 탭 전환
  slow      280ms   바텀시트 · 모달
  easing    cubic-bezier(0.2, 0, 0, 1)
```

`prefers-reduced-motion`이 켜져 있으면 전부 0ms로 떨어뜨린다.

### 2-9. Figma Variables 매핑

토큰은 Figma Variables 컬렉션으로 옮긴다. 이름을 코드와 동일하게 맞춰야 MCP로 오갈 때 매핑이 자동으로 된다.

```
  Color/bg/base          →  --bg-base
  Color/text/primary     →  --text-primary
  Color/rarity/mythic    →  --rarity-mythic
  Number/space/16        →  --space-16
  Number/radius/md       →  --radius-md
```

## 3. 컴포넌트 인벤토리

28종이다. Figma 컴포넌트와 코드 컴포넌트를 1:1로 맞춘다.

### 3-1. 셸과 네비게이션

- **AppShell** — 상단바 · 본문 · (모바일)하단탭바 · 푸터
- **NavTabs** — 데스크톱 상단 가로 탭. 선택 상태에 accent 밑줄
- **BottomTabBar** — 모바일 하단 5탭. 아이콘 + 라벨, 선택 시 accent
- **Avatar** — 대표 계정 프로필 아이콘. 미설정 상태 변형 포함
- **LanguageSwitcher** — en / ko 토글
- **FanContentFooter** — 팬 콘텐츠 정책 고지 (필수)

### 3-2. 목록과 카드

- **SectionCard** — 홈 섹션 컨테이너. 헤더 + "전체 보기" 링크 + 콘텐츠 슬롯
- **RankRow** — 랭킹 행. **플레이어와 클럽 두 변형**을 한 컴포넌트의 variant로
- **RankBadge** — 1·2·3위 채움 / 4위 이상 숫자만. 폭 고정
- **MyAccountTag** — [내 계정] 라벨
- **BrawlerCard** — 그리드 아이템. 이미지 + 이름 + 희귀도. 진행도 오버레이 variant, 미보유 흐림 variant
- **EventCard** — 모드 아이콘 + 모드명 + 맵 이름 + 남은 시간
- **BattleRow** — 최근 전투. 결과별 색상(승/패/무), 트로피 변동
- **RecommendCard** — 추천 결과. 브롤러 + 근거 문구 + [AI에게 더 물어보기]

### 3-3. 배지와 표시

- **RarityBadge** — 7종. 색 + 라벨 텍스트 동반 필수
- **RoleBadge** — 7종. 역할 데이터가 없는 브롤러용 **hidden 상태 포함**
- **TrophyValue** — 트로피 아이콘 + tnum 숫자
- **StatBar** — 체력 · 이동속도 · 사거리. 눈금 범위는 5-4 참조
- **CountdownTimer** — 남은 시간. 1분 간격 갱신, 만료 상태 포함

### 3-4. 상세와 입력

- **DetailPanel** — 데스크톱 사이드 드로어 / 모바일 바텀시트. 같은 컴포넌트의 반응형 variant
- **AbilityItem** — 스타파워 · 가젯 · 기어 공용. 아이콘 + 이름 + 설명
- **TrophyChart** — 일별 트로피 추이. 데이터 1개뿐인 상태 포함
- **TagInput** — 태그 입력 + 유효 문자 검증 + 에러 표시
- **ConfirmModal** — 대표 계정 지정 확인. 제목 + 본문 + [취소][확인]
- **SearchInput** — 영문·한글 동시 검색
- **FilterBar** — 역할 · 희귀도 · 정렬 · 모드 필터 공용
- **CountrySelect** — 랭킹 국가 선택. global 기본

### 3-5. 상태

- **EmptyState** — 아이콘 + 문구 + 액션 버튼
- **ErrorState** — 일반 오류 / **점검(503) 전용 variant**
- **Skeleton** — 카드 · 행 · 그리드 형태 variant

## 4. 화면 상태

Figma에 그려야 할 상태 목록이다. 여기 없는 상태는 만들지 않는다.

### 홈
```
  정상 · 대표계정 있음      네 섹션 전부
  정상 · 대표계정 없음      내 계정 자리에 설정 유도 카드
  로딩                     섹션별 스켈레톤
  부분 실패                한 섹션만 재시도 버튼
  점검                     503 전용 화면
```

### 브롤러
```
  정상 · 대표계정 있음      진행도 오버레이 + 미보유 흐림
  정상 · 대표계정 없음      오버레이 없음
  검색 결과 없음            필터 초기화 버튼
  상세 패널 열림            데스크톱 드로어 / 모바일 바텀시트
```

### 랭킹
```
  플레이어 · 내 계정이 목록 안   행 하이라이트 + [내 계정]
  플레이어 · 내 계정이 200위 밖  상단에 "내 순위: 200위 밖" 안내
  클럽                          플레이어와 같은 레이아웃, 다른 필드
  추가 로딩 중                   목록 하단 스피너
  끝 도달                       "상위 200위까지 제공됩니다"
```

### 이벤트
```
  정상          종료 임박순 15개
  전체 만료      재요청 중 안내
  점검          503 전용 화면
```

### 추천
```
  설문 전            시작 화면
  설문 진행 중        4문항, 진행 표시
  결과 · 대표계정 있음  두 그룹 전부
  결과 · 대표계정 없음  "안 써봤는데 맞을" 그룹만 + 계정 설정 유도
  AI 한도 초과        [더 물어보기] 비활성 + BYOK 안내
```

### 프로필
```
  태그 입력 전        입력 화면 + 태그 찾는 법 안내
  조회 중            스피너
  정상 · 스냅샷 1개   그래프 자리에 "내일부터 추이가 쌓입니다"
  정상 · 그래프 있음   전체 표시
  없는 태그 (404)     형식 재확인 안내
  대표 계정 지정 모달  확인 다이얼로그
  대표 계정 상태      [대표 계정] 배지 + 해제 버튼
```

## 5. Figma 구조

### 5-1. 페이지 구성

```
  00 Cover          문서 링크와 작업 상태
  01 Foundations    색상 · 타이포 · 간격 · 아이콘
  02 Components     인벤토리 28종
  03 Screens (M)    모바일 화면 — 기준 해상도 390 × 844
  04 Screens (D)    데스크톱 — 1440 폭, 레이아웃이 달라지는 화면만
  05 Flows          유저 플로우 (FigJam 또는 다이어그램 프레임)
```

### 5-2. 네이밍

코드 컴포넌트 이름과 정확히 일치시킨다. MCP로 오갈 때 매핑이 자동으로 붙는다.

```
  컴포넌트   RankRow / Player, RankRow / Club
  화면       Home / Default (Account), Ranking / Empty (Out of 200)
  변수       Color/bg/base
```

### 5-3. 프레임 수 추정

```
  모바일 화면 상태   26
  데스크톱 (홈 · 브롤러 그리드 · 상세 패널 · 랭킹)   6
  컴포넌트 시트      3
  Foundations        3
  ─────────────────────
  합계               38 프레임
```

**모바일을 먼저 전부 그리고 데스크톱은 레이아웃이 실제로 달라지는 화면만 만든다.** 두 벌을 다 그리면 76개가 되고 유지가 안 된다.

### 5-4. StatBar 눈금 범위

실측한 106종 전체의 최소·최대다. 그래프 축을 여기 고정해야 브롤러 간 비교가 성립한다.

```
  체력      2000 ~ 6800
  이동속도   540 ~ 820
  사거리     6 ~ 30      (skills.CastingRange — AutoAttackRange 아님)
```

사거리는 `characters.AutoAttackRange`를 쓰면 안 된다. 106종 중 100종이 같은 값이라 막대가 전부 똑같이 그려진다. 상위 문서 4-4를 참조할 것.
