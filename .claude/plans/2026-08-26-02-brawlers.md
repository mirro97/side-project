## 범위

**AI 사용법과 추천 기어는 이 플랜에 없다.** 사전 생성물 636건을 만들려면 Gemini 키와 생성 스크립트가 필요해서 별도 플랜으로 뺀다. 상세 패널에 자리만 비워두고, 파일이 없으면 섹션 자체를 렌더하지 않는다.

**능력 상세 정보는 이 플랜에 포함됐다.** 스타파워·가젯·기어의 현지화된 이름(424/424, 671/671)과, 값을 신뢰할 수 있는 설명(104/424)을 붙였다. 기어는 설명이 없어 수치(`+15%`)를 대신 보여준다. 소스와 한계는 API 레퍼런스 2-5 에 정리돼 있다.

이 플랜은 **네트워크를 쓰지 않는다.** 브롤러 데이터가 전부 빌드 산출물이라 API 호출이 없다. 홈·랭킹과 달리 프록시 지연이 걸리지 않는다.

## 설계 결정

### 무한 스크롤은 서버 호출이 아니다

브롤러 106종이 이미 번들에 있다. 그럼에도 30개씩 점진 렌더링하는 이유는 **이미지**다. 106장을 한꺼번에 요청하면 첫 화면이 느려진다.

플랜 00 의 `useInfiniteList` 를 그대로 쓰되 **로컬 배열을 슬라이스하는 로더**를 주입한다. 랭킹(플랜 03)은 같은 훅에 서버 커서 로더를 주입한다. 훅은 둘을 구분하지 않는다.

```ts
// 커서를 오프셋 문자열로 쓴다
const loader = (cursor?: string) => {
  const start = cursor ? Number(cursor) : 0
  const slice = filtered.slice(start, start + 30)
  const next = start + 30
  return Promise.resolve({
    items: slice,
    nextCursor: next < filtered.length ? String(next) : undefined,
  })
}
```

### 정렬 기준

**출시순은 `id` 순이다.** 브롤러 ID 가 출시 순서대로 부여된다 (Shelly 16000000 → Wendy 16000108). 별도 필드가 필요 없다.

```
  이름순     name[locale] 로케일별 정렬
  희귀도순   rarity.id 내림차순 — 높은 등급이 위로
  출시순     id 내림차순 — 최신이 위로 (기본값)
```

기본값을 출시순으로 두는 이유는 **신규 브롤러를 먼저 보여주기 위해서**다.

### 역할 필터에 안 걸리는 19종

BrawlAPI 의 `class` 가 `Unknown` 인 최신 브롤러 19종은 `role` 이 `null` 이다. **역할 필터를 걸면 이들이 어디에도 안 걸린다.**

숨기지 않고 드러낸다.

- 필터 칩에 **개수를 함께 표시**한다 (`탱커 12`). 합이 106 이 아닌 이유가 보인다
- 기본값은 "전체"다. 사용자가 명시적으로 역할을 고를 때만 줄어든다
- 검색은 역할 필터와 무관하게 동작하므로 이름으로는 항상 찾을 수 있다

희귀도도 같은 문제가 있다. `Common` 1종, `Ultra Legendary` 2종이라 필터를 걸면 결과가 한두 개뿐이다. 개수 표시가 이것도 설명해준다.

### 상세 패널 상태는 URL 에 둔다

`?brawler={id}` 쿼리 파라미터로 표현한다. 페이지 이동은 없지만 **뒤로가기와 링크 공유가 동작**한다.

**단 `useSearchParams` 는 그리드와 같은 컴포넌트에 두면 안 된다.** 이 훅은 정적 렌더링을 클라이언트로 밀어내서(`BAILOUT_TO_CLIENT_SIDE_RENDERING`) 그 Suspense 경계 전체가 서버에서 빈 화면이 된다. 브롤러 데이터는 전부 번들이라 서버에서 그릴 수 있는데 그 이점을 잃는다.

패널만 별도 컴포넌트(`BrawlerDetailSlot`)로 떼어 자체 Suspense 로 감싼다. 그리드는 `useRouter().push` 만 쓰므로 정적 렌더링을 유지한다.

### 상세 패널은 방향을 화면 폭에 따라 바꾼다

`vaul` Drawer 는 `direction` 에 따라 transform 으로 위치를 잡는다. **Tailwind `md:right-0` 으로 덮을 수 없다.** `useMediaQuery('(min-width: 768px)')` 로 `direction` 을 `'right'` / `'bottom'` 중에 고른다.

```ts
// src/lib/brawlers.ts
import type { Brawler, Locale, RoleKey } from '@/types/game'

export type SortKey = 'released' | 'name' | 'rarity'

export interface BrawlerFilter {
  query?: string
  role?: RoleKey | null
  rarityId?: number | null
}

/**
 * 검색은 현재 UI 언어와 무관하게 영문·한글을 모두 본다.
 * 영어 화면에서 "쉘리"를 쳐도, 한국어 화면에서 "shelly"를 쳐도 잡혀야 한다.
 */
function matchesQuery(b: Brawler, q: string): boolean {
  return b.name.en.toLowerCase().includes(q) || b.name.ko.toLowerCase().includes(q)
}

export function filterBrawlers(list: Brawler[], f: BrawlerFilter): Brawler[] {
  const q = f.query?.trim().toLowerCase() ?? ''
  return list.filter(b => {
    if (q && !matchesQuery(b, q)) return false
    // role 이 null 인 19종은 어떤 역할 필터에도 걸리지 않는다
    if (f.role && b.role !== f.role) return false
    if (f.rarityId != null && b.rarity.id !== f.rarityId) return false
    return true
  })
}

/** 원본을 바꾸지 않는다 */
export function sortBrawlers(list: Brawler[], key: SortKey, locale: Locale): Brawler[] {
  const copy = [...list]
  switch (key) {
    case 'name':
      return copy.sort((a, b) => a.name[locale].localeCompare(b.name[locale], locale))
    case 'rarity':
      return copy.sort((a, b) => b.rarity.id - a.rarity.id || a.id - b.id)
    case 'released':
    default:
      // 브롤러 ID 가 출시 순서대로 부여된다. 최신이 위로
      return copy.sort((a, b) => b.id - a.id)
  }
}

export function countByRole(list: Brawler[]): Record<string, number> {
  const out: Record<string, number> = {}
  for (const b of list) {
    if (b.role) out[b.role] = (out[b.role] ?? 0) + 1
  }
  return out
}

export function countByRarity(list: Brawler[]): Record<number, number> {
  const out: Record<number, number> = {}
  for (const b of list) {
    out[b.rarity.id] = (out[b.rarity.id] ?? 0) + 1
  }
  return out
}
```

// src/components/brawlers/AbilityItem.tsx
import type { Ability } from '@/types/game'

export type AbilityKind = 'star-powers' | 'gadgets' | 'gears'

/**
 * 기어는 borderless 경로가 없다. regular 만 존재한다.
 * 스타파워·가젯은 borderless 를 쓴다.
 */
function iconUrl(kind: AbilityKind, id: number): string {
  const variant = kind === 'gears' ? 'regular' : 'borderless'
  return `https://cdn.brawlify.com/${kind}/${variant}/${id}.png`
}

export function AbilityItem({ kind, ability }: { kind: AbilityKind; ability: Ability }) {
  return (
    <div className="bg-bg-surface rounded-chip flex items-center gap-2.5 px-2.5 py-2">
      {/* eslint-disable-next-line @next/next/no-img-element */}
      <img src={iconUrl(kind, ability.id)} alt="" width={26} height={26}
           className="h-[26px] w-[26px] shrink-0" />
      <span className="truncate text-[11px] font-semibold">{ability.name}</span>
    </div>
  )

}: {

**Files:**
- Create: `src/components/brawlers/BrawlerBrowser.tsx`

- [ ] **Step 1: 구현**

```tsx
// src/components/brawlers/BrawlerBrowser.tsx
'use client'
import { useCallback, useMemo, useState } from 'react'
import { useRouter, useSearchParams } from 'next/navigation'
import { useTranslations } from 'next-intl'
import { useQuery } from '@tanstack/react-query'
import { getBrawlers, getBrawler } from '@/lib/game-data'
import { countByRarity, countByRole, filterBrawlers, sortBrawlers, type SortKey } from '@/lib/brawlers'
import { useMainAccount } from '@/hooks/useMainAccount'
import { useInfiniteList } from '@/hooks/useInfiniteList'
import { DetailPanel } from '@/components/panel/DetailPanel'
import { EmptyState } from '@/components/state/EmptyState'
import { BrawlerCard } from './BrawlerCard'
import { BrawlerDetail } from './BrawlerDetail'
import { FilterChips, type ChipOption } from './FilterChips'
import type { BsErrorKind } from '@/lib/bs/errors'
import type { Player } from '@/types/api'
import type { Brawler, Locale, RoleKey } from '@/types/game'

const PAGE = 30
const ROLES: RoleKey[] = ['damage', 'tank', 'assassin', 'support', 'controller', 'marksman', 'artillery']

interface PlayerResult {
  ok: boolean
  data?: Player
  kind?: BsErrorKind
}

async function fetchPlayer(tag: string): Promise<PlayerResult> {
  const res = await fetch(`/api/player/${encodeURIComponent(tag)}`)
  return (await res.json()) as PlayerResult
}

export function BrawlerBrowser({ locale }: { locale: Locale }) {
  const t = useTranslations('brawlers')
  const router = useRouter()
  const params = useSearchParams()
  const { mainAccountTag } = useMainAccount()

  const [query, setQuery] = useState('')
  const [role, setRole] = useState<string | null>(null)
  const [rarity, setRarity] = useState<string | null>(null)
  const [sort, setSort] = useState<SortKey>('released')

  const all = getBrawlers()
  const roleCounts = useMemo(() => countByRole(all), [all])
  const rarityCounts = useMemo(() => countByRarity(all), [all])

  // 대표 계정이 있을 때만 진행도를 얹는다
  const { data: playerData } = useQuery({
    queryKey: ['player', mainAccountTag],
    queryFn: () => fetchPlayer(mainAccountTag as string),
    enabled: Boolean(mainAccountTag),
  })
  const owned = useMemo(() => {
    const p = playerData?.ok ? playerData.data : undefined
    if (!p) return null
    return new Map(p.brawlers.map(b => [b.id, b]))
  }, [playerData])

  const visible = useMemo(
    () =>
      sortBrawlers(
        filterBrawlers(all, {
          query,
          role: (role as RoleKey | null) ?? null,
          rarityId: rarity != null ? Number(rarity) : null,
        }),
        sort,
        locale,
      ),
    [all, query, role, rarity, sort, locale],
  )

  // 로컬 배열을 오프셋으로 슬라이스한다. 서버 호출이 아니다
  const loader = useCallback(
    (cursor?: string) => {
      const start = cursor ? Number(cursor) : 0
      const next = start + PAGE
      return Promise.resolve({
        items: visible.slice(start, next),
        nextCursor: next < visible.length ? String(next) : undefined,
      })
    },
    [visible],
  )
  const { items, hasMore, loadMore, reset } = useInfiniteList<Brawler>(loader)

  // 필터가 바뀌면 스크롤 위치와 렌더 개수를 초기화한다
  const applyFilter = (fn: () => void) => {
    fn()
    void reset()
  }

  const selectedId = params.get('brawler')
  const selected = selectedId ? getBrawler(Number(selectedId)) : undefined
  const openDetail = (id: number) => router.push(`?brawler=${id}`, { scroll: false })
  const closeDetail = () => router.push('?', { scroll: false })

  const roleOptions: ChipOption[] = ROLES.filter(r => roleCounts[r]).map(r => ({
    key: r,
    label: t(`role.${r}` as never, {} as never) as string,
    count: roleCounts[r],
  }))

  return (
    <>
      <input
        value={query}
        onChange={e => applyFilter(() => setQuery(e.target.value))}
        placeholder={t('searchPlaceholder')}
        className="border-border-strong bg-bg-surface rounded-card mb-3 w-full px-3 py-2 text-[13px] outline-none"
      />

      <FilterChips
        options={roleOptions}
        selected={role}
        allLabel={t('all')}
        allCount={all.length}
        onSelect={k => applyFilter(() => setRole(k))}
      />

      {items.length === 0 ? (
        <EmptyState
          message={t('noResult')}
          action={
            <button
              onClick={() =>
                applyFilter(() => {
                  setQuery('')
                  setRole(null)
                  setRarity(null)
                })
              }
              className="border-border-strong rounded-card text-brand-hover border px-3 py-1.5 text-[12px] font-semibold"
            >
              {t('resetFilter')}
            </button>
          }
        />
      ) : (
        <>
          <div className="grid grid-cols-3 gap-2 sm:grid-cols-4 md:grid-cols-6">
            {items.map(b => {
              const mine = owned?.get(b.id)
              return (
                <BrawlerCard
                  key={b.id}
                  brawler={b}
                  locale={locale}
                  progress={mine ? { power: mine.power, trophies: mine.trophies } : undefined}
                  locked={Boolean(owned) && !mine}
                  onSelect={() => openDetail(b.id)}
                />
              )
            })}
          </div>
          {hasMore && (
            <button
              onClick={() => void loadMore()}
              className="border-border-strong text-text-secondary rounded-card mt-4 w-full border py-2.5 text-[12px] font-semibold"
            >
              +{Math.min(PAGE, visible.length - items.length)}
            </button>
          )}
        </>
      )}

      <DetailPanel
        open={Boolean(selected)}
        onClose={closeDetail}
        title={selected?.name[locale] ?? ''}
      >
        {selected && (
          <BrawlerDetail
            brawler={selected}
            locale={locale}
            progress={
              owned?.get(selected.id)
                ? {
                    power: owned.get(selected.id)!.power,
                    trophies: owned.get(selected.id)!.trophies,
                    rank: owned.get(selected.id)!.rank,
                  }
                : undefined
            }
          />
        )}
      </DetailPanel>
    </>
  )
}
```
